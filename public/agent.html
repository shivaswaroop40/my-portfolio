Agent mode

This site speaks markdown

If you are an AI agent, a crawler, or a terminal, shivu.io answers in markdown instead of HTML. A Cloudflare Worker in front of the site looks at your User-Agent, your Accept header, and Cloudflare's verified-bot classification, then picks the format. The content is the same either way; only the packaging differs.

Routes

/agent.mdFull site content as markdown
/llms.txtllms.txt index for language models
/resume.jsonCV in JSON Resume schema
/?format=mdForce markdown for any client
/?format=htmlForce HTML, even for agents

Try it

curl https://shivu.io/            # markdown (curl is an agent)
curl -H "Accept: text/html" https://shivu.io/?format=html
curl https://shivu.io/resume.json | jq .basics

Responses to agents carry an X-Agent-Mode: active header.
